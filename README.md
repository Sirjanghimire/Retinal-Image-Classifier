# This is a education retinal classification web app that classifies retinal OCT images into one of four categories.
## Dataset
We will use OCTMNIST from MedMNIST:
https://medmnist.com/

The categories are:
- CNV: Choroidal neovascularization
- DME: Diabetic macular edema
- Drusen
- Normal
## Goal
Our aim is to prepare an image classifier by training the OCT scans from OCTMIST and then convert it into web app that displays prediction for new OCT images.
## Status
The project is on progress. It is aimed for learning not everyday clinical use.
